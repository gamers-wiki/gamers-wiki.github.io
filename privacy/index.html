プライバシーポリシー

制定：2026/09/08 最終更新：2026/09/08

当サイト「ゲーマーズWiki」（https://gamers-wiki.github.io/）における訪問者の情報の取り扱い、 広告配信、お問い合わせフォーム、外部リンクの取り扱いについて定めます。

運営について

当サイトは、RPGの攻略Wikiをまとめた非公式のポータルサイトで、個人が運営しています。 ゲームの権利者、および後述する各サービスの提供事業者とは、一切の資本関係・提携関係がありません。

取得する情報について

当サイトには、会員登録、コメント投稿、読者による編集などの機能がありません。

ただし、どのページがよく読まれているかを知るため、運営者が用意した仕組みで 閲覧の記録を取得しています。取得するのは次の情報です。

  • 閲覧したページのURLとタイトル
  • 参照元のURL（他のサイトのリンクをたどって来た場合）
  • 端末の種別（パソコン・スマートフォン・タブレットの別）
  • 同じ人の続けての閲覧かどうかを見分けるための、ブラウザに保存した一時的な符号
  • IPアドレスとブラウザの種類から計算した文字列。元に戻せない形に変換したもので、IPアドレスそのものは保存しません

氏名やメールアドレスなど、個人を直接特定できる情報は取得しません。 取得した記録は運営者だけが見るもので、第三者へ提供することはありません。

Googleアナリティクス4

当サイトは、Google LLC が提供するアクセス解析ツール「Googleアナリティクス4」（測定ID：G-764MP9ZHP7）を利用しています。 GoogleアナリティクスはCookieを利用して、訪問者の閲覧履歴を個人が特定できない形で収集します。 収集された情報はGoogleのプライバシーポリシーに従って管理されます。

  • Googleプライバシーポリシー
  • Googleのサービスを使用するサイトやアプリから収集した情報のGoogleによる使用

当サイトは GitHub, Inc. が提供する GitHub Pages で公開しています。 ページの配信にあたり、GitHub がアクセスログ（IPアドレスなど）を記録することがあります。 その取り扱いは GitHub のプライバシーに関する声明に従います。

  • GitHub 一般プライバシーステートメント

Cookie（クッキー）について

Cookie とは、ウェブサイトが訪問者のブラウザに保存する小さなデータのことです。 当サイト自身は Cookie を発行しません。ただし、上に書いた Googleアナリティクスは Cookie を利用します。 また、後述する広告配信サービスが Cookie を使用することがあります。

なお、上に書いた閲覧の記録では、同じ人の続けての閲覧かどうかを見分けるために、 ブラウザの保存領域（ローカルストレージ）へ一時的な符号を保存します。Cookie ではありませんが、 同じくブラウザの設定でサイトのデータを削除すれば、いつでも消せます。

Cookie はブラウザの設定でいつでも無効にしたり削除したりできます。 当サイトのページを読むうえで Cookie は必要ないため、無効にしても閲覧に支障はありません。

広告配信について

当サイトは現在、広告を掲載していません。今後、運営費用にあてるため、 Google LLC が提供する第三者配信の広告サービス「Google AdSense」を導入する予定です。 導入した場合は、以下の取り扱いになります。

  • Google などの第三者配信事業者は、Cookie を使用して、訪問者が当サイトや他のサイトに過去にアクセスした際の情報に基づいて広告を配信します。
  • Google が広告 Cookie を使用することにより、訪問者が当サイトや他のサイトにアクセスした際の情報に基づいて、Google やそのパートナーは適切な広告を表示できます。
  • 訪問者は、広告設定でパーソナライズ広告を無効にできます。 また、aboutads.info から、第三者配信事業者による Cookie の使用を無効にできます。
  • 第三者配信による広告の内容について、当サイトは関与していません。広告に関するお問い合わせは、配信事業者へお願いします。
  • 広告 – ポリシーと規約（Google）

お問い合わせフォームについて

お問い合わせには、Google LLC が提供する「Googleフォーム」を利用しています。 フォームに入力された内容（お名前・メールアドレス・お問い合わせの種類・対象のWiki・該当するページのURL・お問い合わせ内容）は Google のサーバーに送信・保存され、当サイトの運営者がそれを閲覧します。 取得した内容は、お返事とサイトの修正のためだけに使い、第三者に提供することはありません。

Google によるデータの取り扱いは、Google のプライバシーポリシーに従います。 フォームには、お問い合わせに必要な範囲を超える個人情報を入力しないでください。
